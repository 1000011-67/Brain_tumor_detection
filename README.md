# Brain_tumor_detection

It's a deep learning model based on CNN with an accuracy of 92% on test data and 97.6% on training data.

The Dataset - 'https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset' contains 7,022 MRI scans, and is divided into two set - training and testing.
On the basis of classes, it is divided into four classes - 'glioma', 'meningioma', 'no tumor' and 'pituitary'.

I choose this Project, coz I thought, after the boon of AI, still health care sector need much more technological advancement.
Still instead of using AI, Doctors are doing manual checkup, that leads to unnecessary human error and if AI would be used in this case, much of the time and resources will be saved with minimal or negligible error.

To implement this system of technological advancement, I took this step forward so that with the help of this Brain Tumor Detection model, it can be utilised by the Doctors and Healthcare Specialist to give it the MRI scan of the patient, it will predict, whether the patient have tumor or not or which class of tumor the patient have.
